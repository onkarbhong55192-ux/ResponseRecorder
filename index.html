Connect the ResponseRecorder Google account to load requirement photos directly from the Google Drive photo folder. Your CSV and report logic remains unchanged.

1. One-time Requirement Setup

Requirement photos can be loaded automatically from Google Drive. Their filenames are used for automatic CSV matching.

For the online version, use Load Requirement Photos above. Manual image upload remains available as a fallback.

2. Daily CSV Files

Select all CSV files at the same time. The app automatically matches each CSV to the requirement photo using the filename (for example, EkamRcc35.csv ↔ EkamRcc35.png). No manual mapping is required.
